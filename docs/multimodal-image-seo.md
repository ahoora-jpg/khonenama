# Khonenama — Multimodal / Image SEO operating checklist

This checklist applies to public category, guide, local, tool and real published business pages.

## Image selection
- Use a visual that clearly represents the page's subject; avoid generic decoration when a specific product/service visual is available.
- Prefer real business/product/install photos when they are genuinely supplied by the business. Never present editorial stock as a real portfolio/project.
- For editorial stock, use a source with clear reuse rights and keep the visual representative of the page topic.
- Prefer a stable high-resolution source, normally at least 1200 px wide; current editorial hero target is 1600×900.
- Avoid watermarks, text-heavy images, extreme aspect ratios and near-duplicates.

## Crawl and metadata
- Important searchable images must be rendered with `<img>` or `<picture>` and a real `src`; do not rely on CSS background images for indexable visuals.
- Every meaningful image needs concise, descriptive alt text in the page language. Do not keyword-stuff.
- Keep the image close to relevant page text.
- Specify the preferred image in Open Graph and/or schema where the template supports it.
- Allow `max-image-preview:large` on public indexable pages.
- Keep important editorial images listed in `/image-sitemap.xml`.

## Business/profile images
- Only use media belonging to the real published business.
- Cover image alt should describe the visible subject; fall back to the real business name only when no better supplied alt exists.
- Do not invent product photos, prices, stock, reviews, ratings or portfolio work.
- As real product/catalog data is added, pair image URLs with truthful Product/image structured data only when required fields are actually available.

## Monitoring
- Search Console: monitor Web Multimodal Search (Lens, Circle to Search, image upload and Search this image) when data appears.
- Compare landing pages, impressions, clicks and CTR before/after visual changes.
- Check Image Search and Generative AI reports separately; do not infer Lens traffic from ordinary web impressions.
- Use real Search Console queries to decide which visual clusters to expand.
